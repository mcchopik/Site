A small shell that modules are added to. The list of modules lives in a separate repository; each one is downloaded only after you agree to that module, and kept only if it hashes to the hash published with it — so what runs is what the list's author published, byte for byte. A module is a jar, and what it declares about itself is shown before you agree to it.
