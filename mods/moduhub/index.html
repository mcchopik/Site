ModuHub

A client-side Fabric mod for Minecraft 26.2 that is a shell for modules. The mod itself does very little on purpose: what you actually want — a boost, a counter on the screen, a tweak to the game — is a module, published in a separate repository and added without a new build of the mod.

Early skeleton — no modules published yet
How it behaves
  • Nothing is installed without being asked. Every module is one button, and pressing it says what the module is, who published it, how large it is, the full address it comes from, and what it asks for.
  • Nothing is kept that does not match. Each module has a SHA-256 published with it, and the file is thrown away unless it hashes to it.
  • Nothing can do more than it says. A module declares what it needs — and the list of what is possible is fixed by the mod, shown to you in your own language before anything is downloaded.
  • Nothing is code. A module is a description. No jar, no code loaded into the game, so a repository that is taken over cannot run anything.
  • Your language, or English. Module text is written per language; anything missing falls back to English rather than showing a key.
  • No hotkeys. Every setting is on the settings screen Mod Menu shows.
Install

Put moduhub-*.jar in your mods folder. Fabric Loader 0.19.3+, Fabric API and Java 25 are required; Mod Menu is optional and adds the button that opens the module list. Windows, macOS, Linux and Android launchers such as PojavLauncher are supported. There is no release yet — the mod is being built, and the first modules are next.

Клиентский мод на Fabric для Minecraft 26.2, который представляет собой оболочку для модулей. Сам мод намеренно делает очень мало: то, что вам нужно — буст, счётчик на экране, правка поведения игры — это модуль, опубликованный в отдельном репозитории и добавляемый без новой сборки мода.

Как он себя ведёт
  • Ничего не ставится без вопроса. Каждый модуль — одна кнопка, и по нажатию вам говорят, что это, кто опубликовал, сколько весит, с какого полного адреса и что он просит.
  • Ничего не остаётся, если не совпало. С каждым модулем публикуется его SHA-256, и файл отбрасывается, если его хеш не тот.
  • Ничего не может больше, чем заявляет. Модуль объявляет, что ему нужно, а список возможного задан самим модом и показывается вам вашим языком до начала загрузки.
  • Ничего не является кодом. Модуль — это описание. Ни jar, ни кода, загружаемого в игру, поэтому захваченный репозиторий ничего не сможет выполнить.
  • Ваш язык или английский. Текст модуля написан по языкам; если чего-то нет, показывается английский, а не ключ.
  • Горячих клавиш нет. Все настройки — на экране настроек, который показывает Mod Menu.
Установка

Положите moduhub-*.jar в папку mods. Нужны Fabric Loader 0.19.3+, Fabric API и Java 25; Mod Menu необязателен и добавляет кнопку, открывающую список модулей. Поддерживаются Windows, macOS, Linux и Android-лаунчеры вроде PojavLauncher. Релиза пока нет — мод делается, следом первые модули.

Клієнтський мод на Fabric для Minecraft 26.2, який є оболонкою для модулів. Сам мод навмисно робить дуже мало: те, що вам потрібно — буст, лічильник на екрані, правка поведінки гри — це модуль, опублікований в окремому репозиторії та доданий без нової збірки мода.

Ранній каркас — модулів поки немає
Як він поводиться
  • Нічого не встановлюється без запитання. Кожен модуль — одна кнопка, і після натискання вам кажуть, що це, хто опублікував, скільки важить, з якої повної адреси і що він просить.
  • Нічого не залишається, якщо не збіглося. З кожним модулем публікується його SHA-256, і файл відкидається, якщо його хеш не той.
  • Ніщо не може більше, ніж заявляє. Модуль оголошує, що йому потрібно, а список можливого заданий самим модом і показується вам вашою мовою до початку завантаження.
  • Ніщо не є кодом. Модуль — це опис. Ні jar, ні коду, що завантажується в гру, тож захоплений репозиторій нічого не зможе виконати.
  • Ваша мова або англійська. Текст модуля написано за мовами; якщо чогось немає, показується англійська, а не ключ.
  • Гарячих клавіш немає. Усі налаштування — на екрані налаштувань, який показує Mod Menu.
Встановлення

Покладіть moduhub-*.jar у теку mods. Потрібні Fabric Loader 0.19.3+, Fabric API і Java 25; Mod Menu необов'язковий і додає кнопку, що відкриває список модулів. Підтримуються Windows, macOS, Linux і Android-лаунчери на кшталт PojavLauncher. Релізу ще немає — мод робиться, далі перші модулі.
