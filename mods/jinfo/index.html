JInfo

A free, open-source, client-side Fabric mod for Minecraft 26.2 that gives every player a small profile: up to 500 characters, 10 lines and 6 links, stored in a Cloudflare Worker + D1. Works for both licensed and offline accounts, and needs no game server of its own.

0.1 — beta
How it works
  • Shift + Right-click a player — a compact card with the head from their skin. Hover the head to read the formatted profile; click it to open the full card. Link previews are never clickable.
  • Full profile screen — a rotatable 3D skin (hat, jacket, sleeve and pants layer toggles), nickname, the whole text, your photo and one button per service in that service's colour. Clicking a button first asks “Open link? Domain: …” with the full URL; links are never opened automatically.
  • Skin in your profile — settings (Mod Menu or /jinfo settings) let you use your current skin, an https URL or a local PNG, pick classic/slim and preview it in 3D. Other players see that skin in the card and full screen; auto mode stays compatible with other skin mods.
  • Two editors — /jinfo edit in game (colours, styles, services, live preview) and /jinfo web in your browser on 127.0.0.1 with a one-time token.
  • Your own photo — {photo} https://…/photo.png or /jinfo photo <url> adds a direct image link to the profile information in the full profile and web preview; the card head always stays the player's skin.
  • Templates and preview — four ready-made profiles (streamer, developer, gamer, simple) via /jinfo template <id> or the “Templates” button, and /jinfo preview [nick] shows a profile exactly as others see it.
  • Commands — /jinfo help, edit, web, set, me, view <nick>, template, preview, photo, clear, settings, update. The key P opens your own profile.
  • Both account types — licensed UUID v4 is confirmed through Mojang (joinServer + hasJoined); an offline UUID v3 is confirmed by an Ed25519 key that stays on your computer. Offline profiles are marked as unverified.
  • Safe links — only https. javascript:, file:, localhost, IP addresses and user@host are rejected; built-in services must match their domain list; shorteners and punycode are flagged in the confirmation window. Control, zero-width and bidi characters are stripped.
  • Reports — one report per person per profile per day.
  • Your language — English, Russian, Belarusian and Ukrainian.
  • Mod Menu — optional settings button in the mod list: language, Shift+right-click gesture, in-game editor, web editor and your profile.
No mod? Use a server component

The same repository has a Fabric server mod for 26.2 (server branch) and a Paper plugin for 26.2 (paper branch). Both provide the same profiles through chat commands such as /jinfo me, view, set and clear — with no web page, no open port and no client mod required. Admin commands are available under /jinfo.

Updates

On join the mod asks GitHub for the latest release and tells you in chat if a newer one exists; /jinfo update checks on demand. Each release publishes an update.json with the version, file name and SHA-256. Downloading and installing is left to you — the message links to the release.

Install

Put jinfo-*.jar in your mods folder. Fabric Loader 0.20.1+, Fabric API and Java 25 are required. The mod is client-side, so a server does not need it. It is a beta: expect rough edges.

Бесплатный открытый клиентский мод на Fabric для Minecraft 26.2, который даёт каждому игроку небольшой профиль: до 500 символов, 10 строк и 6 ссылок, который хранится в Cloudflare Worker + D1. Работает и с лицензионными, и с offline аккаунтами, своего игрового сервера не требует.

0.1 — бета
Как он работает
  • Shift + ПКМ по игроку — компактная карточка с головой из скина. Наведи на голову, чтобы прочитать оформленный профиль; клик открывает полную карточку. Ссылки в подсказке не кликабельны.
  • Полный экран профиля — 3D-скин с вращением мышью (слои шляпы, куртки, рукавов и штанов включаются кнопками), ник, весь текст, фото и по кнопке на каждый сервис в его цвете. Клик сначала спрашивает «Открыть ссылку? Домен: …» с полной ссылкой; сами ссылки никогда не открываются.
  • Скин в профиле — в настройках (Mod Menu или /jinfo settings) можно выбрать текущий скин, https-ссылку или локальный PNG, модель classic/slim и посмотреть 3D-предпросмотр. Другие игроки видят этот скин в карточке и полном экране; режим «авто» совместим с другими скин-модами.
  • Два редактора — /jinfo edit в игре (цвета, стили, сервисы, живой предпросмотр) и /jinfo web в браузере на 127.0.0.1 с одноразовым токеном.
  • Своё фото — {photo} https://…/photo.png или /jinfo photo <url> добавляет прямую ссылку на картинку к информации профиля в полном экране и веб-просмотре; голова в карточке всегда остаётся скином игрока.
  • Шаблоны и предпросмотр — четыре готовых профиля (стример, разработчик, геймер, простой) в /jinfo template <id> или кнопкой «Шаблоны», а /jinfo preview [ник] показывает профиль так, как его видят другие.
  • Команды — /jinfo help, edit, web, set, me, view <ник>, template, preview, photo, clear, settings, update. Клавиша P открывает свой профиль.
  • Оба типа аккаунтов — лицензионный UUID v4 подтверждается через Mojang (joinServer + hasJoined); offline UUID v3 — ключом Ed25519, который остаётся на вашем компьютере. Offline-профили помечаются как неподтверждённые.
  • Безопасные ссылки — только https. javascript:, file:, localhost, IP-адреса и user@host отклоняются; для встроенных сервисов домен обязан совпадать со списком; сокращатели и punycode помечаются в окне подтверждения. Управляющие, невидимые и bidi-символы вырезаются.
  • Жалобы — одна жалоба на человека на профиль в сутки.
  • Ваш язык — английский, русский, белорусский и украинский.
  • Mod Menu — необязательная кнопка настроек в списке модов: язык, жест Shift+ПКМ, редактор в игре, веб-редактор и свой профиль.

Обновления

При входе мод спрашивает у GitHub последний релиз и пишет в чат, если вышла версия новее; /jinfo update проверяет по запросу. С каждым релизом публикуется update.json с версией, именем файла и SHA-256. Скачивание и установка остаются за вами — в сообщении есть ссылка на релиз.

Установка

  • Повний екран профілю — 3D-скін з обертанням мишею (шари капелюха, куртки, рукавів і штанів вмикаються кнопками), нік, увесь текст, фото і по кнопці на кожен сервіс у його кольорі. Клік спершу питає «Відкрити посилання? Домен: …» з повним посиланням; самі посилання ніколи не відкриваються.
  • Скін у профілі — у налаштуваннях (Mod Menu або /jinfo settings) можна вибрати поточний скін, https-посилання або локальний PNG, модель classic/slim і подивитися 3D-перегляд. Інші гравці бачать цей скін у картці та повному екрані; режим «авто» сумісний з іншими скін-модами.
  • Два редактори — /jinfo edit у грі (кольори, стилі, сервіси, живий попередній перегляд) і /jinfo web у браузері на 127.0.0.1 з одноразовим токеном.

  • Шаблони й попередній перегляд — чотири готові профілі (стрімер, розробник, геймер, простий) у /jinfo template <id> або кнопкою «Шаблони», а /jinfo preview [нік] показує профіль так, як його бачать інші.
  • Команди — /jinfo help, edit, web, set, me, view <нік>, template, preview, photo, clear, settings, update. Клавіша P відкриває власний профіль.
  • Обидва типи акаунтів — ліцензійний UUID v4 підтверджується через Mojang (joinServer + hasJoined); offline UUID v3 — ключем Ed25519, який залишається на вашому комп'ютері. Offline-профілі позначені як непідтверджені.
