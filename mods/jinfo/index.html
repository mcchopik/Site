JInfo

A free, open-source, client-side Fabric mod for Minecraft 26.2 that gives every player a small profile: up to 500 characters, 10 lines and 6 links, stored in a Cloudflare Worker + D1. Works for both licensed and offline accounts, and needs no game server of its own.

0.1beta — beta
How it works
  • Shift + Right-click a player — a compact card with the head from their skin. Hover the head to read the formatted profile; click it to open the full card. Link previews are never clickable.
  • Full profile screen — avatar, nickname, the whole text and one button per service in that service's colour. Clicking a button first asks “Open link? Domain: …” with the full URL; links are never opened automatically.
  • Two editors — /jinfo edit in game (colours, styles, services, live preview) and /jinfo web in your browser on 127.0.0.1 with a one-time token.
  • Commands — /jinfo help, edit, web, set, me, view <nick>, clear, settings, update. The key P opens your own profile.
  • Both account types — licensed UUID v4 is confirmed through Mojang (joinServer + hasJoined); an offline UUID v3 is confirmed by an Ed25519 key that stays on your computer. Offline profiles are marked as unverified.
  • Safe links — only https. javascript:, file:, localhost, IP addresses and user@host are rejected; built-in services must match their domain list; shorteners and punycode are flagged in the confirmation window. Control, zero-width and bidi characters are stripped.
  • Reports — one report per person per profile per day.
  • Your language — English, Russian and Ukrainian.
Updates

On join the mod asks GitHub for the latest release and tells you in chat if a newer one exists; /jinfo update checks on demand. Each release publishes an update.json with the version, file name and SHA-256. Downloading and installing is left to you — the message links to the release.

Install

Put jinfo-*.jar in your mods folder. Fabric Loader 0.20.1+, Fabric API and Java 25 are required. The mod is client-side, so a server does not need it. It is a beta: expect rough edges.

Как он работает
  • Shift + ПКМ по игроку — компактная карточка с головой из скина. Наведи на голову, чтобы прочитать оформленный профиль; клик открывает полную карточку. Ссылки в подсказке не кликабельны.
  • Полный экран профиля — аватар, ник, весь текст и по кнопке на каждый сервис в его цвете. Клик сначала спрашивает «Открыть ссылку? Домен: …» с полной ссылкой; сами ссылки никогда не открываются.
  • Два редактора — /jinfo edit в игре (цвета, стили, сервисы, живой предпросмотр) и /jinfo web в браузере на 127.0.0.1 с одноразовым токеном.
  • Команды — /jinfo help, edit, web, set, me, view <ник>, clear, settings, update. Клавиша P открывает свой профиль.
  • Оба типа аккаунтов — лицензионный UUID v4 подтверждается через Mojang (joinServer + hasJoined); offline UUID v3 — ключом Ed25519, который остаётся на вашем компьютере. Offline-профили помечаются как неподтверждённые.
  • Безопасные ссылки — только https. javascript:, file:, localhost, IP-адреса и user@host отклоняются; для встроенных сервисов домен обязан совпадать со списком; сокращатели и punycode помечаются в окне подтверждения. Управляющие, невидимые и bidi-символы вырезаются.
  • Жалобы — одна жалоба на человека на профиль в сутки.
  • Ваш язык — английский, русский и украинский.
Обновления

При входе мод спрашивает у GitHub последний релиз и пишет в чат, если вышла версия новее; /jinfo update проверяет по запросу. С каждым релизом публикуется update.json с версией, именем файла и SHA-256. Скачивание и установка остаются за вами — в сообщении есть ссылка на релиз.
