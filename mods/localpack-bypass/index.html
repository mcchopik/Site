localpack-bypass

A free, open-source, client-side Fabric mod for Minecraft 26.2 that makes server resource packs painless. Instead of downloading the same pack every time you join, it compares the SHA-1 of the pack the server sends with the ZIP files already in your resourcepacks folder. When it finds a match the pack is switched on silently, so you join without a prompt and without waiting.

0.0.1.2026-alpha-build-beta-release — experimental
How it works
  • A pack you already have is switched on silently. No prompt, no download.
  • A new or changed pack gives you one screen with Download all resource packs on it. The packs are saved to resourcepacks/localpack-<sha1>.zip, checked by SHA-1, switched on and written into your options — in one step, with the resources reloaded once.
  • Declining leaves the server, the way it does in vanilla.
  • A newer version of a pack switches the older one off. The file stays on your disk, so going back is instant.
  • Nothing fails silently. A download that did not work, a checksum that did not match, or a file the game would not switch on is reported on the screen — or as a notification, if there is no screen to report it on.
  • Your language. The screen and the messages follow the game language; the mod ships translations for 38 of them.
Settings (Mod Menu)
  • Folder for downloaded packs — where packs are kept. Empty means the game's own resourcepacks folder. Any other folder works, including another drive or an Android shared folder; packs are then also copied into resourcepacks before they are switched on, because that is the only folder the game itself reads.
  • Remember servers you said yes to — a server you have already taken packs from is not asked about again. The answer is written into the game's own per-server Server Resource Packs setting as well.
  • Keep packs from other servers — leave it on to keep what you already have; turn it off to start each server with only that server's packs.
  • Wait before asking — how long to collect a batch before the screen appears. Servers send all their packs at once, so waiting turns several questions into one.
  • Give up after and Tries — how long one download may take, and how many times a failed one is retried. A checksum that does not match counts as a failure, because that is what a half-finished transfer looks like.
  • Keep a record — every pack a server sends is written down: which server, which address, the checksum, the size, what happened to it and how long it took. It is a file on your own computer, and nothing is sent anywhere.
  • Downloaded packs — what the mod has downloaded, grouped by the server it came from, showing whether each is on, off, or gone from the folder. Press one to switch it on or off, and forget one whose file has disappeared. Forget everything clears what the mod remembers and never deletes a pack file.
  • No hotkeys. Everything is on that settings screen.
Updates

Once a day the mod asks GitHub for the latest release. If it is newer than the build you are running, the title screen offers to install it: the new jar is downloaded and its SHA-256 is checked against the update.json published with that release, the old jar is deleted and the new one moved into mods/, and you restart the game. On Windows a jar that is loaded cannot be deleted, so a short generated script waits for the game to exit and does it for you; on Android, Linux and macOS the running jar is simply replaced. Everything the updater touches is under mods/ and config/localpack-bypass/.

The check is a plain anonymous GitHub API request — no token, no account. The mod has no telemetry and no server of its own. Skipping a version is remembered, and -Dlocalpack.bypass.updateCheck=false turns updates off entirely. One caveat: 0.0.1.2026-alpha-build-beta-release sorts below the earlier 0.0.3-beta, so a build numbered that or higher will not be offered this one automatically and has to be replaced by hand.

Install

Put localpack-bypass-*.jar in your mods folder. Fabric Loader 0.19.3+, Fabric API and Java 25 are required. Windows, macOS, Linux and Android launchers such as PojavLauncher are supported — every file the mod touches is resolved from the launcher's game directory, so no folder has to be set up by hand. Mod Menu is optional and adds the settings screen described above. It is experimental: it has not been tested extensively, so use it at your own risk.

Бесплатный открытый клиентский мод на Fabric для Minecraft 26.2, который избавляет от мучений с серверными ресурспаками. Вместо того чтобы качать один и тот же пак при каждом входе, он сравнивает SHA-1 пака, который прислал сервер, с ZIP-файлами, уже лежащими в папке resourcepacks. Если нашлось совпадение, пак тихо включается, и вы заходите без вопроса и без ожидания.

0.0.1.2026-alpha-build-beta-release — экспериментальный
Как он работает
  • Пак, который у вас уже есть, включается тихо. Ни вопроса, ни загрузки.
  • Новый или изменившийся пак — один экран с кнопкой Скачать все ресурспаки. Паки сохраняются в resourcepacks/localpack-<sha1>.zip, проверяются по SHA-1, включаются и записываются в ваши настройки — одним шагом, с одной перезагрузкой ресурсов.
  • Отказ отключает от сервера, как в ванилле.
  • Более новая версия пака выключает старую. Файл остаётся на диске, поэтому вернуться можно мгновенно.
  • Ничего не проваливается молча. Неудачная загрузка, не совпавшая сумма или файл, который игра не стала включать, сообщаются на экране — или уведомлением, если экрана в этот момент нет.
  • Ваш язык. Экран и сообщения идут за языком игры; в моде есть переводы на 38 языков.
Настройки (Mod Menu)
  • Папка для скачанных паков — где они лежат. Пусто — значит папка игры resourcepacks. Подойдёт и любая другая папка, включая другой диск или общую папку Android; тогда паки перед включением ещё и копируются в resourcepacks, потому что больше никакую папку игра сама не читает.
  • Помнить серверы, где вы согласились — сервер, от которого вы уже брали паки, больше не спрашивает. Ответ записывается и в собственную настройку игры Server Resource Packs для этого сервера.
  • Сохранять паки других серверов — оставьте включённым, чтобы не терять уже скачанное; выключите, чтобы входить на каждый сервер только с его паками.
  • Ждать перед вопросом — сколько собирать паки перед показом экрана. Сервер присылает их все сразу, так что ожидание превращает несколько вопросов в один.
  • Сдаваться через и Попытки — сколько может длиться одна загрузка и сколько раз повторять неудачную. Не совпавшая сумма считается неудачей: именно так выглядит оборванная передача.
  • Вести запись — каждый пак, присланный сервером, записывается: какой сервер, какой адрес, сумма, размер, что с ним стало и сколько это заняло. Это файл на вашем компьютере, и никуда он не отправляется.
  • Скачанные паки — что мод скачал, сгруппировано по серверам, с пометкой, включён пак, выключен или пропал из папки. Нажатие включает и выключает, а пак, чей файл исчез, можно забыть. Забыть всё стирает память мода и никогда не удаляет сами файлы паков.
  • Горячих клавиш нет. Всё на этом экране настроек.
Обновления

Раз в сутки мод спрашивает у GitHub последний релиз. Если он новее вашей сборки, титульный экран предлагает его поставить: новый jar скачивается, его SHA-256 сверяется с update.json, опубликованным вместе с релизом, старый jar удаляется, новый переносится в mods/, и вы перезапускаете игру. В Windows загруженный jar удалить нельзя, поэтому короткий сгенерированный скрипт дожидается выхода игры и делает это за вас; в Android, Linux и macOS запущенный jar просто заменяется. Всё, к чему прикасается апдейтер, лежит в mods/ и config/localpack-bypass/.

Проверка — обычный анонимный запрос к API GitHub: без токена и без аккаунта. У мода нет ни телеметрии, ни своего сервера. Пропущенная версия запоминается, а -Dlocalpack.bypass.updateCheck=false выключает обновления совсем. Одна оговорка: 0.0.1.2026-alpha-build-beta-release сортируется ниже прежней 0.0.3-beta, поэтому сборке с такой версией или выше эта не будет предложена автоматически — её придётся заменить руками.

Установка

Положите localpack-bypass-*.jar в папку mods. Нужны Fabric Loader 0.19.3+, Fabric API и Java 25. Поддерживаются Windows, macOS, Linux и Android-лаунчеры вроде PojavLauncher — все файлы мод ищет от игровой папки лаунчера, так что настраивать папки руками не нужно. Mod Menu необязателен и добавляет описанный выше экран настроек. Мод экспериментальный: тщательно он не проверялся, так что пользуйтесь на свой риск.

Безкоштовний відкритий клієнтський мод на Fabric для Minecraft 26.2, який позбавляє від мороки із серверними ресурспаками. Замість того щоб завантажувати той самий пак щоразу при вході, він порівнює SHA-1 пака, який надіслав сервер, із ZIP-файлами, що вже лежать у теці resourcepacks. Якщо збіг знайдено, пак тихо вмикається, і ви заходите без запитання й без очікування.

0.0.1.2026-alpha-build-beta-release — експериментальний
Як він працює
  • Пак, який у вас уже є, вмикається тихо. Ні запитання, ні завантаження.
  • Новий або змінений пак — один екран із кнопкою Завантажити всі ресурспаки. Паки зберігаються в resourcepacks/localpack-<sha1>.zip, перевіряються за SHA-1, вмикаються й записуються у ваші налаштування — одним кроком, з одним перезавантаженням ресурсів.
  • Відмова від'єднує від сервера, як у ванілі.
  • Новіша версія пака вимикає старішу. Файл залишається на диску, тож повернутися можна миттєво.
  • Ніщо не зникає мовчки. Невдале завантаження, сума, що не збіглася, або файл, який гра не стала вмикати, повідомляються на екрані — або сповіщенням, якщо екрана в цей момент немає.
  • Ваша мова. Екран і повідомлення йдуть за мовою гри; у моді є переклади на 38 мов.
Налаштування (Mod Menu)
  • Тека для завантажених паків — де вони лежать. Порожньо — отже тека гри resourcepacks. Підійде й будь-яка інша тека, зокрема інший диск або спільна тека Android; тоді паки перед увімкненням ще й копіюються в resourcepacks, бо більше жодної теки гра сама не читає.
  • Пам'ятати сервери, де ви погодилися — сервер, від якого ви вже брали паки, більше не запитує. Відповідь записується і у власне налаштування гри Server Resource Packs для цього сервера.
  • Зберігати паки інших серверів — залиште увімкненим, щоб не втрачати вже завантажене; вимкніть, щоб заходити на кожен сервер лише з його паками.
  • Чекати перед запитанням — скільки збирати паки перед показом екрана. Сервер надсилає їх усі одразу, тож очікування перетворює кілька запитань на одне.
  • Здаватися через і Спроби — скільки може тривати одне завантаження і скільки разів повторювати невдале. Сума, що не збіглася, вважається невдачею: саме так виглядає обірвана передача.
  • Вести запис — кожен пак, надісланий сервером, записується: який сервер, яка адреса, сума, розмір, що з ним сталося і скільки це зайняло. Це файл на вашому комп'ютері, і нікуди він не надсилається.
  • Завантажені паки — що мод завантажив, згруповано за серверами, із позначкою, увімкнено пак, вимкнено чи він зник із теки. Натискання вмикає й вимикає, а пак, чий файл зник, можна забути. Забути все стирає пам'ять мода і ніколи не видаляє самі файли паків.
  • Гарячих клавіш немає. Усе на цьому екрані налаштувань.
Оновлення

Раз на добу мод питає в GitHub останній реліз. Якщо він новіший за вашу збірку, титульний екран пропонує його встановити: новий jar завантажується, його SHA-256 звіряється з update.json, опублікованим разом із релізом, старий jar видаляється, новий переноситься в mods/, і ви перезапускаєте гру. У Windows завантажений jar видалити не можна, тож короткий згенерований скрипт чекає на вихід гри і робить це за вас; в Android, Linux і macOS запущений jar просто замінюється. Усе, до чого торкається апдейтер, лежить у mods/ і config/localpack-bypass/.

Перевірка — звичайний анонімний запит до API GitHub: без токена й без акаунта. У мода немає ні телеметрії, ні власного сервера. Пропущена версія запам'ятовується, а -Dlocalpack.bypass.updateCheck=false вимикає оновлення зовсім. Одне застереження: 0.0.1.2026-alpha-build-beta-release сортується нижче за попередню 0.0.3-beta, тож збірці з такою версією або вищою ця не буде запропонована автоматично — її доведеться замінити руками.

Встановлення

Покладіть localpack-bypass-*.jar у теку mods. Потрібні Fabric Loader 0.19.3+, Fabric API і Java 25. Підтримуються Windows, macOS, Linux і Android-лаунчери на кшталт PojavLauncher — усі файли мод шукає від ігрової теки лаунчера, тож налаштовувати теки руками не потрібно. Mod Menu необов'язковий і додає описаний вище екран налаштувань. Мод експериментальний: ретельно він не перевірявся, тож користуйтеся на свій ризик.
